## Java

- [JavaGuide](https://github.com/Snailclimb/JavaGuide "JavaGuide"):【Hướng dẫn học Java + Phỏng vấn】Tài liệu tổng hợp hầu hết các kiến thức cốt lõi mà một lập trình viên Java cần nắm vững.
- [toBeBetterJavaer](https://github.com/itwanger/toBeBetterJavaer)：Hướng dẫn học Java dễ hiểu, hài hước, bao gồm Java cơ bản, Java Collection Framework, lập trình đa luồng, JVM, phát triển Java doanh nghiệp (Git, SSM, Spring Boot) và nhiều chủ đề khác.
- [interview-guide](https://github.com/csguide-dabai/interview-guide)：Tổng hợp những kiến thức trọng tâm thường gặp trong các buổi phỏng vấn Backend, hỗ trợ sinh viên chuẩn bị cho các kỳ tuyển dụng lập trình viên.
- [advanced-java](https://github.com/doocs/advanced-java "advanced-java"): Lộ trình nâng cao dành cho kỹ sư Java Internet, bao gồm lập trình đồng thời, hệ thống phân tán, tính sẵn sàng cao, microservices, xử lý dữ liệu lớn và nhiều lĩnh vực khác.
- [toBeTopJavaer](https://github.com/hollischuang/toBeTopJavaer "toBeTopJavaer")：Con đường trở thành chuyên gia Java.
- [technology-talk](https://github.com/aalansehaiyang/technology-talk): Tổng hợp các framework phổ biến trong hệ sinh thái Java, middleware mã nguồn mở, kiến trúc hệ thống, cơ sở dữ liệu, kiến trúc của các công ty lớn, thư viện bên thứ ba, quản lý dự án, xử lý sự cố production, phát triển bản thân và tư duy kỹ thuật.
- [JCSprout](https://github.com/crossoverJie/JCSprout): Kho kiến thức cốt lõi về Java đang được xây dựng và phát triển.
- [bestJavaer](https://github.com/crisxuan/bestJavaer): Chuỗi hướng dẫn giúp bạn trở thành một lập trình viên Java giỏi hơn.
- [java-design-patterns](https://github.com/iluwatar/java-design-patterns "java-design-patterns")：Các mẫu thiết kế (Design Patterns) được triển khai bằng Java.

## Kiến thức nền tảng Khoa học Máy tính

- [cs-self-learning](https://github.com/PKUFlyingPig/cs-self-learning)：Hướng dẫn tự học Khoa học Máy tính, tổng hợp các khóa học chất lượng cao từ nhiều trường đại học hàng đầu thế giới.
- [CS-Notes](https://github.com/CyC2018/CS-Notes "CS-Notes")：Tài liệu nền tảng phục vụ phỏng vấn kỹ thuật, lời giải LeetCode, phỏng vấn Backend, Java, tuyển dụng mùa xuân/mùa thu, hệ điều hành, mạng máy tính và thiết kế hệ thống.
- [Waking-Up](https://github.com/wolverinn/Waking-Up)：Tổng hợp đầy đủ các câu hỏi phỏng vấn về kiến thức nền tảng máy tính (Mạng máy tính, Hệ điều hành, Cơ sở dữ liệu, Git...).

## Thiết kế hệ thống

### SpringBoot

- [springboot-guide](https://github.com/Snailclimb/springboot-guide)：Tổng hợp các kiến thức cốt lõi về Spring Boot. Dựa trên Spring Boot 2.19+.
- [SpringAll](https://github.com/wuyouzhuguli/SpringAll "SpringAll")：Lộ trình học từ cơ bản đến nâng cao với Spring Boot, Spring Boot & Shiro, Spring Cloud, Spring Security, Spring Security OAuth2 và mã nguồn minh họa cho loạt bài viết về Spring.
- [Springboot-Notebook](https://github.com/chengxy-nds/Springboot-Notebook): Bộ ví dụ thực tế sử dụng Spring Boot kết hợp Redis, RabbitMQ, Elasticsearch, MongoDB, Spring Cloud, Kafka, SkyWalking và các công nghệ Internet phổ biến khác để triển khai nhiều chức năng thường gặp.
- [springboot-learning-example](https://github.com/JeffLi1993/springboot-learning-example "springboot-learning-example")：Các ví dụ thực hành Spring Boot, phù hợp cho người mới bắt đầu cũng như củng cố kiến thức cốt lõi.
- [spring-boot-demo](https://github.com/xkcoding/spring-boot-demo "spring-boot-demo")：Dự án thực hành chuyên sâu về Spring Boot với 63 demo tích hợp, trong đó đã hoàn thành 52 demo.
- [SpringBoot-Labs](https://github.com/YunaiV/SpringBoot-Labs)：Loạt hướng dẫn học Spring Boot.

## Sách mã nguồn mở

- [《高并发的哲学原理》](https://github.com/johnlui/PPHC)：Cuốn sách bàn về triết lý đằng sau các hệ thống có khả năng xử lý đồng thời cao (High Concurrency), tập trung vào việc tìm điểm nghẽn và phân tách chúng.
- [《Effective Java（第 3 版）》中英对照版](https://github.com/clxering/Effective-Java-3rd-edition-Chinese-English-bilingual)：Phiên bản song ngữ Trung - Anh của **Effective Java (Ấn bản thứ 3)**, hỗ trợ học tập theo từng chương.
- [《DDIA（设计数据密集型应用）》中文版](https://github.com/Vonng/ddia)：Bản dịch tiếng Trung của **Designing Data-Intensive Applications (DDIA)**.
- [《凤凰架构》](https://github.com/fenixsoft/awesome-fenix)：Cuốn sách thảo luận về cách xây dựng các hệ thống phân tán quy mô lớn có độ tin cậy cao.
- [《分布式系统模式》中文版](https://github.com/dreamhead/patterns-of-distributed-systems)：Bản dịch tiếng Trung của **Patterns of Distributed Systems**.
