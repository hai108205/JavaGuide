This **curated technical book collection** is designed for programmers who want to build a solid foundation and grow their engineering skills over the long term. It includes carefully selected books on Java, databases, distributed systems, computer science fundamentals, search engines, and software quality.

This reading list is maintained based on the open-source project [CodingDocs/awesome-cs](https://github.com/CodingDocs/awesome-cs) and is continuously updated. Feel free to recommend books you find valuable in the project's [Issues](https://github.com/CodingDocs/awesome-cs/issues) so we can build a higher-quality technical reading list together.

## Who Is This For?

- Programmers who want to strengthen their fundamentals but are unsure which books to read.
- Students preparing for campus recruitment, experienced hiring, or backend engineering interviews at top tech companies.
- Backend developers looking to transition from fragmented articles to systematic learning.
- Engineers who want to improve their architecture design, database knowledge, code quality, and software engineering skills.

## Learning Focus

- A longer reading list is not necessarily better. Choose one or two books that best match your current level and study them thoroughly.
- Computer science fundamentals, Java, and databases are the core skills every backend developer should master.
- Distributed systems and search engine technologies are best studied after gaining some real-world engineering experience.
- Books on software quality help improve code maintainability, testing practices, and team collaboration.
- Combine reading with hands-on projects, interview practice, and source code exploration to avoid learning concepts only at a theoretical level.

## Recommended Reading Order

1. [Computer Science Fundamentals Books](./cs-basics.md): Start with operating systems, computer networks, data structures, and algorithms.
2. [Java Books](./java.md): Learn Java fundamentals, concurrency, the JVM, frameworks, and performance optimization.
3. [Database Books](./database.md): Master MySQL, Redis, NoSQL, and data engineering concepts.
4. [Distributed Systems Books](./distributed-system.md): After gaining project experience, dive deeper into distributed systems theory, architecture, and middleware.
5. [Software Quality Books](./software-quality.md): Improve long-term engineering productivity through refactoring, testing, software engineering practices, and collaboration.
